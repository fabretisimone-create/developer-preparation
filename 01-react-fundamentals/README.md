# React Fundamentals

Projeto desenvolvido como parte da minha preparação para uma posição de desenvolvimento de software.

## Sobre o projeto

Este projeto foi criado para praticar os fundamentos do React utilizando Vite.

O objetivo é aprender, na prática, como criar aplicações React, organizar componentes, trabalhar com JSX, gerenciar estado e responder a interações do usuário.

## Tecnologias utilizadas

* React
* Vite
* JavaScript
* HTML
* CSS
* ESLint
* Git
* GitHub

## Conceitos estudados

Durante este projeto serão praticados:

* Estrutura de uma aplicação React
* Componentes
* JSX
* Props
* Eventos
* Estado
* `useState`
* Renderização de elementos
* Organização de código
* Hot Module Replacement (HMR)
* Boas práticas de desenvolvimento

## Exercícios

### Exercício 01 — Meu primeiro componente

Criação e utilização de um componente React simples.

**Conceitos:**

* Componentes
* JSX
* `export`
* `import`

### Exercício 02 — JSX

Prática de JSX e utilização de JavaScript dentro da interface.

### Exercício 03 — Props

Prática de passagem de informações entre componentes.

### Exercício 04 — Eventos

Prática de eventos e interação do usuário.

### Exercício 05 — Estado com useState

Prática de gerenciamento de estado utilizando o Hook `useState`.

### Exercício 06 — Renderização de listas

Prática de renderização de dados utilizando listas e o método `map()`.

## Como executar o projeto

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, acesse o endereço exibido pelo Vite no terminal.
